# Digital Image Processing Lab Codes

This repository contains basic Digital Image Processing (DIP) implementations using Python and NumPy.  
The codes are written for learning purposes and include both spatial domain and frequency domain operations.

---

# Topics Covered

## 1. Image Channels
- RGB Channels
- Grayscale Conversion
- Channel Visualization

File:
- `1_channels.ipynb`

---

## 2. Basic Intensity Transformations
- Negative Transformation
- Log Transformation
- Gamma Correction

File:
- `2_basic_intensity_transform.ipynb`

---

## 3. Geometric Transformations
- Translation
- Rotation
- Scaling

File:
- `3_geometric_transform.ipynb`

---

## 4. Image Sharpening
- Edge Detection
- Sobel Operator
- Image Sharpening using Edge Information

File:
- `4_image_sharpening.ipynb`

---

## 5. Image Blurring
- Box Blur
- Convolution Operation
- Padding

File:
- `5_image_blurring.ipynb`

---

## 6. Frequency Domain
- Fourier Transform
- FFT
- Frequency Spectrum Visualization

File:
- `6_frequency_domain.ipynb`

---

## 7. Frequency Components Visualization
- Low Frequency
- High Frequency
- Frequency Component Analysis

File:
- `7_frequency_components_visualization.ipynb`
